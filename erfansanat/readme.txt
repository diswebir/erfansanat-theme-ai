# قالب عرفان صنعت اصفهان

قالب اختصاصی وردپرس/ووکامرس برای عرفان صنعت اصفهان، ساخته‌شده از مرجع استاتیک تأییدشده. راست‌به‌چپ و فارسی، بدون صفحه‌ساز.

## پیش‌نیازها

- وردپرس ۷.۱ یا بالاتر
- PHP 8.4 یا بالاتر
- WooCommerce (فروشگاه، سبد و حساب کاربری)
- WordPress به‌صورت `fa_IR` و راست‌به‌چپ

## نصب

1. پوشهٔ `erfansanat` را در `wp-content/themes/` قرار دهید.
2. در پیشخوان، از **نمایش › پوسته‌ها** قالب را فعال کنید.
3. اگر WooCommerce تازه نصب شده، برگه‌های سبد/پرداخت/حساب را یک‌بار بسازید.

## ساختار

| مسیر | کار |
| --- | --- |
| `assets/` | دارایی‌های منتقل‌شده از مرجع (`manifest.json` هش هر فایل را نگه می‌دارد) |
| `assets/admin/` | فونت وزیرمتن و استایل پنل و متاباکس‌ها |
| `inc/` | منطق قالب: انواع نوشته، داده، سئو، فرم‌ها، جستجوی زنده |
| `inc/Data/` | لایهٔ خواندن متای قدیمی و تبدیل آن به API تمیز |
| `inc/Admin/` | پیشخوان اختصاصی، مدیریت بخش‌ها و متاباکس‌ها |
| `inc/Forms/` | نقطهٔ پایانی فرم‌های عمومی و صندوق پیام خصوصی |
| `template-parts/` | اجزای قابل استفادهٔ مجدد، گروه‌بندی‌شده بر اساس صفحه |
| `page-templates/` | قالب‌های انتخابی برگه (تماس، استخدام، پروژه‌های برگزیده) |
| `languages/` | فایل‌های ترجمه |

## قالب‌های برگه

- **تماس با ما** — فرم واقعی با اعتبارسنجی سمت سرور
- **فرصت‌های شغلی** — بدون فرم آپلود رزومه تا زمانی که مقصد و مدت نگهداری تعیین شود
- **پروژه‌های برگزیده** — جدا از آرشیو کامل پروژه‌ها

## فونت

وزیرمتن در سه زیرمجموعه (`arabic`، `latin-ext`، `latin`) در `assets/fonts/` بسته‌بندی شده است. فرانت‌اند فایل‌های پرکاربرد را از پیش بارگذاری می‌کند و پیشخوان آن‌ها را روی همهٔ صفحه‌ها از `assets/admin/font.css` می‌گیرد. هیچ درخواستی به سرویس بیرونی زده نمی‌شود.

## فرم‌ها و حریم خصوصی

پیام‌های فرم ابتدا در دیتابیس ذخیره می‌شوند (نوع نوشتهٔ خصوصی `erfansanat_message`) و سپس ایمیل اطلاع‌رسانی می‌رود؛ اگر ایمیل شکست بخورد پیام از بین نمی‌رود. از فرستنده فقط یک هش از نشانی IP نگه داشته می‌شود، نه خود نشانی.

مدت نگهداری پیش‌فرض «همیشگی» است. برای تعیین یک پنجره:

```php
add_filter( 'erfansanat_message_retention_days', fn() => 365 );
```

مقصد ایمیل اطلاع‌رسانی از `admin_email` خوانده می‌شود و قابل تغییر است:

```php
add_filter( 'erfansanat_form_recipient', fn() => 'sales@example.com' );
```

## سئو

قالب canonical، توضیح متا، Open Graph و داده‌های ساختاریافته را خودش تولید می‌کند. **اگر Yoast، Rank Math یا SEOPress فعال باشد، قالب کنار می‌کشد** تا دو برچسب رقیب روی یک صفحه نیاید.

## توسعه

```bash
source tools/env.sh              # PHP و Node قابل حمل
bash tools/run-php-tests.sh temp/phase-07-projects-blog-and-pages/tests
python3 temp/phase-08-ajax-filters-and-audit/tests/check-http.py
tools/phpcs erfansanat
```

هر تغییر در `assets/css`، `assets/js`، `assets/fonts` یا `assets/images` باید در `PATCHED` داخل `tools/build-asset-manifest.py` ثبت شود و `manifest.json` بازتولید شود، وگرنه قرارداد بایت‌به‌بایت فاز ۱ می‌شکند.

## ترجمه

رشته‌های خود قالب فارسی نوشته شده‌اند، چون سایت فارسی است و در زمان اجرا چیزی برای ترجمه نمانده. برای استفاده از قالب روی سایتی به زبان دیگر:

- `languages/erfansanat.pot` فهرست کامل ۶۶۹ رشته با دامنهٔ متنی `erfansanat` است.
- آن را به `<locale>.po` کپی کنید، `msgstr`ها را پر کنید و با `python3 tools/compile-po.py erfansanat/languages/<locale>.po` به `.mo` تبدیل کنید.
- اگر رشته‌ای اضافه یا عوض کردید، `python3 tools/make-pot.py` را اجرا کنید تا قالب دوباره ساخته شود. `wp i18n make-pot` در محیط بسته کار نمی‌کند چون به `develop.svn.wordpress.org` وصل می‌شود.

هیچ فراخوانی gettext بدون دامنهٔ `erfansanat` نیست؛ تست فاز ۸.۳ روی همهٔ فایل‌های قالب این را بررسی می‌کند.

## تصویر پیش‌نمایش

`screenshot.png` یک قاب از تصویر هیروی خود قالب (`assets/images/light-element.jpg`) است، نه عکس صفحه. گرفتن عکس واقعی از صفحه نیاز به مرورگر دارد که در محیط ساخت قابل نصب نبود؛ تصویر تخت رنگی هم ساخته شد و پاک شد چون پیش‌نمایش گمراه‌کننده است. برای جایگزینی، از `/` سایت اسکرین‌شات ۱۲۰۰×۹۰۰ بگیرید و همین فایل را عوض کنید.
