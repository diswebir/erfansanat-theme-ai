# Task 8.8 — فرم استخدام با آپلود رزومه

| فیلد | مقدار |
|---|---|
| فاز | 8 — جایگزینی Native جستجو/فیلترها، فرم‌ها و ممیزی نهایی |
| اندازه | `M` — متوسط (~۱ روز) |
| وابستگی | `Task 8.6`، `Task 7.21` |
| وضعیت | `[PENDING]` |
| تست | `tests/test-task-08.php` |

## ۱. هدف

فرم استخدام (`data-contact-form` در برگه recruitment) با آپلود PDF (حداکثر ۵MB)، اعتبارسنجی MIME واقعی، نام فایل تصادفی و اتصال به موقعیت شغلی.

## ۲. فایل‌های هدف

- `inc/Forms/RecruitmentHandler.php`

## ۳. مراحل پیاده‌سازی (گام‌به‌گام)

1. اعتبارسنجی با `finfo` + `wp_check_filetype_and_ext`.
2. ذخیره در `uploads/es-forms/` با نام هش‌شده.
3. پیوست فایل به ایمیل اعلان (اختیاری toggle).

## ۴. شروط پاس شدن (Pass Conditions)

> هر شرط باید در تست خودکار به `PASS` تبدیل شود؛ یک شرط `PENDING` یعنی تسک تمام نشده است.

- [ ] **P1** — PDF معتبر پذیرفته شود
- [ ] **P2** — فایل `.php`/`.exe` با MIME جعلی رد شود
- [ ] **P3** — حجم > ۵MB رد شود
- [ ] **P4** — نام فایل تصادفی و غیرقابل حدس باشد

## ۵. تست‌های خودکار

- `پذیرش PDF`
- `رد فایل مخرب`
- `محدودیت حجم`
- `نام‌گذاری`

## ۶. چرخه اجرایی (۶ گام اجباری)

| گام | اقدام |
|---|---|
| `[READ MEMORY]` | `temp/PROJECT_MEMORY.md` + `temp/STATIC_TEMPLATE_MAP.md` + این فایل |
| `[THINK & PLAN]` | تحلیل مارک‌آپ/داده مربوطه و طرح اتصال |
| `[WRITE TEST]` | تکمیل `tests/test-task-XX.php` (تبدیل `pending()` به `check()`) |
| `[IMPLEMENT]` | پیاده‌سازی بدون حذف کلاس/DOM/هوک |
| `[RUN TEST]` | اجرا تا ۱۰۰٪ PASS + ثبت در `QA_REFLECTION_LOG.md` |
| `[UPDATE MEMORY]` | آپدیت `PROJECT_MEMORY.md`, `MASTER_PLAN.md` + کامیت |

## ۷. ضدالگوها (Anti-patterns) — انجام نده

- طراحی مجدد مارک‌آپ یا افزودن کلاس Tailwind جدید (قانون R1)
- تغییر فایل `assets/js/main.js` یا `assets/css/styles.css` (md5 باید ثابت بماند)
- استفاده از `TODO`/`...`/حذف بخشی از HTML برای کوتاه‌سازی (قانون R6)
- خواندن/نوشتن متا با املای «تصحیح‌شده» (مثل `english_title` به‌جای `english_titl`)
