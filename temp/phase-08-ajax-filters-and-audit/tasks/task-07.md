## ۱. هدف

فرم استعلام برای محصولات `true_sale="false"`: پاپ‌آپ با پیش‌پر کردن نام/لینک محصول، همان زیرساخت امن فرم، و ذخیره با `type=inquiry`.

## ۲. فایل‌های هدف

- `template-parts/product/inquiry-modal.php`
- `inc/Forms/InquiryHandler.php`

## ۳. مراحل پیاده‌سازی (گام‌به‌گام)

1. پیش‌پر کردن `post_id` و عنوان محصول (بدون اعتماد به ورودی سمت کلاینت؛ سرور عنوان را از ID می‌خواند).
2. ذخیره با `type=inquiry` و `meta_json` شامل شناسه محصول.
3. بستن با Escape و بازگشت فوکوس.

## ۴. شروط پاس شدن (Pass Conditions)

> هر شرط باید در تست خودکار به `PASS` تبدیل شود؛ یک شرط `PENDING` یعنی تسک تمام نشده است.

- [ ] **P1** — فقط محصول استعلامی دکمه داشته باشد
- [ ] **P2** — عنوان/لینک از سرور خوانده شود (نه از input مخفی قابل تغییر)
- [ ] **P3** — ردیف با `type=inquiry` ذخیره شود

## ۵. تست‌های خودکار

- `شرط نمایش`
- `امنیت پیش‌پرکردن`
- `نوع ذخیره`

## ۶. چرخه اجرایی (۶ گام اجباری)

## ۷. ضدالگوها (Anti-patterns) — انجام نده

- طراحی مجدد مارک‌آپ یا افزودن کلاس Tailwind جدید (قانون R1)
- تغییر فایل `assets/js/main.js` یا `assets/css/styles.css` (md5 باید ثابت بماند)
- استفاده از `TODO`/`...`/حذف بخشی از HTML برای کوتاه‌سازی (قانون R6)
- خواندن/نوشتن متا با املای «تصحیح‌شده» (مثل `english_title` به‌جای `english_titl`)
