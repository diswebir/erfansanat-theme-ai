| فیلد | مقدار |
|---|---|
| فاز | 2 — فریم‌ورک داشبورد اختصاصی ادمین و Section Builder |
| اندازه | `L` — بزرگ (~۲ روز) |
| وابستگی | `Task 2.4` |
| وضعیت | `[PENDING]` |
| تست | `tests/test-task-07.php` |

## ۱. هدف

تب‌های سراسری هدر/فوتر با تمام مقادیر پیش‌فرض استخراج‌شده از میرور: نوار اعلان، شعار، لوگو، تلفن‌ها (شامل مدیر فروش)، ایمیل، آدرس، ساعات کاری، شبکه‌های اجتماعی، متن کپی‌رایت، دکمه بازگشت به بالا.

## ۲. فایل‌های هدف

- `inc/Admin/Tabs/HeaderTab.php`
- `inc/Admin/Tabs/FooterTab.php`

## ۳. مراحل پیاده‌سازی (گام‌به‌گام)

1. استخراج دقیق متون از `index.html` به `Defaults.php` (بدون تغییر جمله‌بندی).
2. فیلدهای هدر: نمایش نوار اعلان (toggle)، متن، لینک، لینک‌های دوم، لوگو (media).
3. فیلدهای فوتر: کپی‌رایت، لینک‌های سریع (repeater)، دسته‌ها (خودکار از DB)، تماس‌ها.
4. شبکه‌های اجتماعی: repeater `{نام، آیکون، url}` با آیکون از لیست SVG مجاز.

## ۴. شروط پاس شدن (Pass Conditions)

> هر شرط باید در تست خودکار به `PASS` تبدیل شود؛ یک شرط `PENDING` یعنی تسک تمام نشده است.

- [ ] **P1** — هیچ متن هاردکدی از هدر/فوتر در فایل‌های فرانت نماند
- [ ] **P2** — خاموش‌کردن نوار اعلان، کل بلوک را حذف کند (نه رندر خالی)
- [ ] **P3** — شبکه اجتماعی با URL نامعتبر ذخیره نشود

## ۵. تست‌های خودکار

- `اسکن هاردکد`
- `حذف کامل بلوک`
- `اعتبار URL`

## ۶. چرخه اجرایی (۶ گام اجباری)

| گام | اقدام |
|---|---|
| `[READ MEMORY]` | `temp/PROJECT_MEMORY.md` + `temp/STATIC_TEMPLATE_MAP.md` + این فایل |
| `[THINK & PLAN]` | تحلیل مارک‌آپ/داده مربوطه و طرح اتصال |
| `[WRITE TEST]` | تکمیل `tests/test-task-XX.php` (تبدیل `pending()` به `check()`) |
| `[IMPLEMENT]` | پیاده‌سازی بدون حذف کلاس/DOM/هوک |
| `[RUN TEST]` | اجرا تا ۱۰۰٪ PASS + ثبت در `QA_REFLECTION_LOG.md` |
| `[UPDATE MEMORY]` | آپدیت `PROJECT_MEMORY.md`, `MASTER_PLAN.md` + کامیت |

## ۷. ضدالگوها (Anti-patterns) — انجام نده

- طراحی مجدد مارک‌آپ یا افزودن کلاس Tailwind جدید (قانون R1)
- تغییر فایل `assets/js/main.js` یا `assets/css/styles.css` (md5 باید ثابت بماند)
- استفاده از `TODO`/`...`/حذف بخشی از HTML برای کوتاه‌سازی (قانون R6)
- خواندن/نوشتن متا با املای «تصحیح‌شده» (مثل `english_title` به‌جای `english_titl`)
