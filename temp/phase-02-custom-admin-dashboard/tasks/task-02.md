## جزئیات پیاده‌سازی

1. استخراج تمام متون هدر/فوتر از `index.html` به‌عنوان Default
2. اتصال فیلدها به `header.php`/`footer.php` (تسک ۴.۱ مصرف‌کننده است)
3. مدیریت نوار اعلان (روشن/خاموش، متن، لینک)
4. مدیریت شبکه‌های اجتماعی با آیکون‌های inline موجود
5. اسکریپت سفارشی هدر/فوتر با خروجی escape‌شده
