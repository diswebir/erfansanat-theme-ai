# محیط آزمایشی محلی عرفان صنعت

تاریخ راه‌اندازی: 2026-11-03

## وضعیت

- وردپرس `7.1.4`، ووکامرس `10.9.4`، PHP `8.4.27` و SQLite integration `3.1.2` نصب و فعال هستند.
- زبان سایت `fa_IR`، راست‌چین `RTL` و واحد پول ووکامرس `IRT` است.
- قالب فعال فعلاً `Twenty Twenty-Five` است. قالب اختصاصی عرفان صنعت هنوز ساخته نشده؛ تبدیل باید پس از تأیید کاربر از فاز ۱ شروع شود.
- همه داده‌ها ساختگی‌اند و نباید به سایت زنده منتقل شوند. قیمت‌ها، سفارش‌ها، دیدگاه‌ها و آمار واقعی نیستند.
- سایت زنده، دیتابیس تولید و افزونه‌های حذف‌شدنی هنوز بررسی یا تغییر نکرده‌اند.

## پیش‌نمایش و ورود

- پیش‌نمایش وردپرس: پورت `8080` در Live Preview همین محیط.
- پیش‌نمایش مرجع استاتیک: پورت `8000` (این یکی وردپرس نیست).
- مدیریت وردپرس: `/wp-admin/`
- نام کاربری مدیر: `erfansanat_admin`
- گذرواژه مدیر و مشتری آزمایشی در فایل محلی و Git‌نشدهٔ `.local/credentials.json` قرار دارد. این فایل نباید commit یا در سایت زنده استفاده شود.

## بازتولید محیط

```bash
bash tools/setup.sh
bash tools/setup-wordpress.sh
tools/php -S 0.0.0.0:8080 -t .local/wordpress tools/local/router.php
```

در یک ترمینال دیگر:

```bash
bash tools/test-local.sh
```

- هسته، افزونه‌ها، دیتابیس، رسانه‌های آپلودشده و اعتبارنامه‌ها در `.local/` هستند و در Git ثبت نمی‌شوند.
- دیتابیس SQLite در `.local/data/database.sqlite` و بیرون از documentroot عمومی قرار دارد.
- اسکریپپت‌ها فقط از GitHub/codeload/API مجاز استفاده می‌کنند و نسخه‌ها را pin می‌کنند.
- فایل رسمی ZIP ووکامرس در این sandbox به میزبان غیرمجاز redirect می‌شد؛ بنابراین از mirror توزیع pin‌شده استفاده شد. همه فایل‌های مشترک آن با تگ رسمی `10.9.4` هش یکسان دارند و هش خود mirror نیز بررسی می‌شود. این معادل تأیید امضای رسمی ZIP نیست.
- ترجمه هسته فارسی از mirror قدیمی‌تر استفاده می‌کند؛ رشته‌های جدید ممکن است انگلیسی بمانند. بسته رسمی زبان ووکامرس نصب شده است.

## نتایج آزمون محلی

آخرین اجرا: `bash tools/test-local.sh`

- بررسی نحو PHP: موفق.
- ۲۶ شرط پذیرش runtime وردپرس/ووکامرس/داده: موفق.
- آزمون HTTP عمومی، REST، ورود مدیر، پیشخوان محصولات/پروژه‌ها/خدمات/تنظیمات ووکامرس، سبد و پرداخت پس از افزودن محصول: موفق.
- مسیرهای حساس `wp-config.php`، `wp-content/db.php` و PHP داخل uploads: مسدود.
- میزبان پیش‌نمایش Arena و HTTPS forwarding: موفق.
- اجرای دوباره seeder تعداد رکوردها را تغییر نداد.
- فایل‌های `static-mirror/` بدون تغییر باقی ماندند.

## محدودیت‌ها

- این محیط SQLite/PHP-Wasm است و جای آزمون MySQL/MariaDB، LiteSpeed، درگاه پرداخت، ایمیل واقعی یا هاست تولید را نمی‌گیرد.
- درخواست‌های خارجی وردپرس در محیط محلی مسدودند؛ هشدارهای `translations_api`/به‌روزرسانی در لاگ محلی ناشی از همین محدودیت شبکه است.
- هنوز سازگاری با دیتابیس واقعی، افزونه‌های همکار، SEOPress، ورود پیامکی، پنل کاربری و پرداخت تأیید نشده است.
- هیچ ادعای آمادگی تولید یا عملکرد واقعی از این محیط قابل استنتاج نیست.
